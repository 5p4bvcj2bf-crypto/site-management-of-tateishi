# Site management of Tateishi

キッチン・ユニットバス取り付け工事のための現場管理アプリ。
現場・担当者・施工会社の管理、毎日の現場状況確認（日報）、クレームの内容・重要度・納期（対応期限）の管理ができます。

## 公開URL

https://5p4bvcj2bf-crypto.github.io/site-management-of-tateishi/

アドレスを知っている人は誰でもブラウザから利用できます（インストール不要）。

## 主な機能

- **ダッシュボード**: 管理中の現場数、本日の日次確認状況、未完了クレーム、期限超過/間近のアラートを一目で確認
- **現場管理**: 現場名・設備種別（キッチン / ユニットバスを選択）・担当者・施工会社・ステータス・進捗率の登録・編集
- **日次確認（日報）**: 日付・天気・作業員数・作業内容・安全朝礼の実施・事故/ヒヤリハットの記録
- **クレーム管理**: 受付日・内容・重要度（高/中/低）・対応状態・対応期限（納期）の管理。期限超過は赤色で警告表示
- **メンバー切替**: ヘッダーで利用者を切り替え。管理者は全データを編集でき、それ以外のメンバーが登録したデータは閲覧のみ

## データの保存について

データは各利用者のブラウザ内（localStorage）に保存されます。
端末やブラウザを変えるとデータは別々になります。共有のデータベース化が必要な場合は別途対応が必要です。
